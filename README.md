\# Qsoftware Financial Management System



A simple financial management system developed as part of the Qsoftware portfolio.



\## Features



\- Income registration

\- Expense registration

\- Financial transaction listing

\- Transaction editing and deletion

\- Financial dashboard

\- Income, expenses and current balance indicators



\## Technologies



\- PHP 8.2

\- Laravel 12

\- SQLite

\- Blade

\- Bootstrap 5
